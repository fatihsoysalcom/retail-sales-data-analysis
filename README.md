# Retail Sales Data Analysis

This Python script demonstrates fundamental data analysis tasks for a retail data analyst. It includes calculating total sales by category, identifying top-selling products, analyzing sales trends over time, and computing average sale values per product using Pandas.

## Language

`python`

## How to Run

Save the code as `retail_analysis.py` and run it from your terminal using: `python retail_analysis.py`
